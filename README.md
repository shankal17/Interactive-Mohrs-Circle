# Mohr's Circle Demo

Interactive Mohr's-circle visualization for plane stress.

Take a look if you want: https://shankal17.github.io/Interactive-Mohrs-Circle/

## Formatting

Install the formatter once from the project root:

```sh
npm install
```

Format all tracked source files:

```sh
npm run format
```

Check formatting without changing files:

```sh
npm run format:check
```
